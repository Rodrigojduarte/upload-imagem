Gestão de Imagens de Produtos

Envie imagens para criar URLs oficiais no bucket da empresa. Nesta etapa, o sistema apenas cria a URL e registra a imagem. A publicação automática na Bling ainda não será feita.
Use “Adicionar” para produto novo ou para incluir novas fotos. Use “Substituir” quando as imagens antigas do produto deverão ser trocadas futuramente.
Clique ou arraste até 10 imagens. Marque a imagem principal.
Para URLs externas, o sistema irá importar as imagens para o nosso bucket.
